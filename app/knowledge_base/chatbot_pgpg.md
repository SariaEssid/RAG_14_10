# S'authentifier via le Robot chatbot : préciser mot de passe et nom d'utilisateur (Mots Clés : note résultat)
Pour s'authentifier via the robot chatbot à fin de consulter tes notes et tes résutats, il faut préciser votre Nom Utilisateur et votre Mot de Passe en strictement respectant le format suivant : ```username=VotreIdentifiant ; password=VotreMotDePassePGPG```
- Impossible d'initialiser ou modifier le ```Mot de passe``` ou ```Nom d'utilisateur``` via le robot Chatbot

#### Que faire si l’utilisateur presente son inquiétude concernant la sécurité de ses informations personnelles et refuse de fournir ses identifiants ?

-> Il faut :
- L’informer qu'il dois fournir ses identifiants sous le format demandé pour accéder aux résultats
- Le **rassurer** sur la sécurité de ses informations

---

## **VotreIdentifiant** ou **identifiant**
votre identifiant doit etre sous format ```X-000-000``` (Exemple : ```P-111-222```)

---

## **Username** ou **Nom Utilisateur** ou **VotreIdentifiant** ou **identifiant**
Le ```nom Utilisateur``` ou ```username``` : votre identifiant sous format ```X-000-000``` (Exemple : ```P-111-222```)

#### questions fréquents :
- je mets quoi dans ```VotreIdentifiant```
- C'est quoi ```VotreIdentifiant```
- C'est quoi ```Identifiant```
- je mets quoi dans ```username```
- je mets quoi comme ```nom utilisateur```
- je mets quoi dans le champ ```nom utilisateur```
-  je mets quoi dans ```identifiant```

---

## **Password** ou **Mot de Passe** ou **VotreMotDePassePGPG**
Le ```mot de passe``` ou ```password``` : même mot de passe de compte de la plateforme PGPG (Plateforme Passage de grades)

#### questions fréquents :
- je mets quoi dans ```VotreMotDePassePGPG```
- C'est quoi ```VotreMotDePassePGPG```
- C'est quoi ``` Mot De Passe PGPG```
- je mets quoi dans ```mot de passe```

## Échec d'authentification : Nom utilisateur et/ou Mot de passe incorrect(s)
Si l'utilisateur reçoit un message d'échec d'authentificaion

->

alors, ```Nom utilisateur``` et/ou ```Mot de passe``` sont incorrect(s) : il doit corriger son insertion.
