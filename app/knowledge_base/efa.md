# Enseignant Formateur Associé (EFA)

## ✔ Enseignant Formateur Associé

- ```Assistant Technologue```est équivalent à ```Enseignant Formateur Associé```
- Il présente un niveau d’entrée dans le parcours pédagogique. 
- Enseignant débutant.
- Expérience pédagogique encore en développement.
- Spécialités elligibles : Technologies de l'information(tic), Électromecanique(em), Math, Génie Civil(gc), Génie Énergitique(ged)
- Spécialité ```Langues``` est interdite pour ce grade

Si le candidat est un ```EFA``` (premier grade : grade début de carrière pour toutes les spécialités except Langues) -> C'est possible de postuler pour le grade suivant ```Enseignant Formateur (EF)``` :

-> ⛔ Impossible de postuler pour le même grade ```Enseignant Formateur Associé (EFA)```

-> ⛔ Impossible de sauter le grade suivant ```EF``` et postuler directement pour les grades supérieurs ```EFS``` et ```EFM```

---

## ✔ Responsabilités de **EFA**

- Assurer des cours ou travaux pratiques.
- Appliquer des supports pédagogiques existants.
- Respecter les directives pédagogiques établies.
- Ne gérer pas les sessions

---

## ✔ Niveau d’Autonomie de **EFA**

- Encadrement par des enseignants plus expérimentés
- Contribution principalement opérationnelle.

---

## Assistant Technologue

Le grade :

- ```Assistant Technologue``` (ancien grade)

est équivalent au grade :

- ```Enseignant Formateur Associé``` (nouveau grade)

=> Il s’agit d’une différence/distinction  de dénomination uniquement.

#### ✅ La mission de ```Assistant Technologue``` est la même de ```Enseignant Formateur Associé``` :
- Assurer l’enseignement et les travaux pratiques
- Appliquer les supports pédagogiques définis
- Respecter les consignes académiques
- Ne gérer pas les sessions de passage de grades : Il participe à une session de passage de grade
