# 1. Connaissances de base - conseils et recommendations pour réussir l'épreuve ```Connaissances de base```

## 1.1 Test QCM - conseils et recommendations pour réussir l'épreuve ```Test QCM```

### Révision systématique
Maîtrisez les références bibliographiques et les fondamentaux de votre spécialité.

### Simulation
Entraînez-vous avec des QCM chronométrés pour apprendre à gérer le temps (durée : 1h30).

---

## 1.2 Dissertations - conseils et recommendations pour réussir l'épreuve ```Dissertations```

### Structure
Respectez une structure claire :
- Introduction
- Développement
- Conclusion

Formulez une problématique claire et cohérente.


Soignez :
- la syntaxe
- le vocabulaire
- l’orthographe

Rédigez des brouillons structurés avant la version finale.


Règles selon le type de candidat :

```Candidat Enseignant Formateur (EF)```  
- Déposer 2 dissertations :
  - Dissertation en Français
  - Dissertation en Anglais

```Candidat Enseignant de Langue Communication et Citoyenneté (ELCC)```  
- Déposer 1 dissertation :
  - Français OU Anglais selon votre specialité

---

# 2. Production - conseils et recommendations pour réussir l'épreuve ```Production```

## 2.1 Productions pédagogiques - conseils et recommendations pour réussir l'épreuve ```Productions pédagogiques```

### 2.1.1 Capsules pédagogiques - conseils et recommendations pour réussir l'épreuve ```Capsules pédagogiques```

#### Contenu
Choisissez un concept pédagogiquement fort.  
Le script doit être :
- concis
- dynamique
- adapté à un public étudiant

#### Technique
La qualité audio et vidéo doit être irréprochable.  
Utilisez des supports visuels professionnels :
- animations
- sous-titres
- visuels pédagogiques

Répétez à l’oral afin d’avoir une élocution fluide et naturelle.

#### Règles selon le type de candidat

```Candidat Enseignant Formateur (EF)```  
- Déposer 2 capsules pédagogiques :
  - Française
  - Anglaise

```Candidat Enseignant de Langue Communication et Citoyenneté (ELCC)```  
- Déposer 1 capsule pédagogique :
  - Française OU Anglaise selon votre specialité

---

### 2.1.2 Séquence d’enseignement ou Plateforme de TP - conseils et recommendations pour réussir l'épreuve ```Séquence d’enseignement ou Plateforme de TP```

#### Choix
Choisissez la formule qui valorise le mieux vos compétences :
- pédagogie interactive
- innovation technique

#### Démonstration
Pour une ```séquence d’enseignement``` :
- montrer l’engagement des étudiants

Pour une ```plateforme de TP``` :
- démontrer l’ergonomie
- prouver son utilité pédagogique

#### Documentation
Rédigez un document de présentation expliquant :
- vos choix pédagogiques
- vos choix techniques

#### Règles selon le type de candidat

```Candidat Enseignant Formateur (EF)```  
- Choisir :
  - Séquence d’Enseignement  
  OU
  - Plateforme de TP

```Candidat Enseignant de Langue Communication et Citoyenneté (ELCC)```  
- Déposer uniquement : Séquence d’Enseignement

---

### 2.1.3 Supports pédagogiques - conseils et recommendations pour réussir l'épreuve **Supports pédagogiques**

#### Exhaustivité
Présentez plusieurs types de ressources :
- cours
- TD
- projets
- quiz
- Travaux remis par les étudiants

#### Accessibilité
Organisez les ressources de manière :
- logique
- intuitive

Intégrez si possible :
- éléments interactifs
- contenus multimédias

---

## 2.2 Production RDI - conseils et recommendations pour réussir l'épreuve **Production RDI**

### Sélection
Présentez vos réalisations les plus significatives :
- articles scientifiques
- brevets
- logiciels
- autres productions de recherche

### Impact Production RDI
Mesurez et indiquez les retombées :
- citations
- téléchargements
- applications concrètes

Incluez un projet RDI futur :
- ambitieux
- réaliste

# 3. Dossier et Entretien avec Jury

## 3.1 Dossier - conseils et recommendations pour réussir l'épreuve **Dossier**

Remplissez soigneusement toutes les sections du template officiel.

Joignez toutes les pièces justificatives :
- certificats
- publications
- attestations

Pour l'Auto-évaluation de Dossier, soyez :
- honnête
- stratégique

Mettez en avant vos points forts sans exagération.

---

## 3.2 Entretien avec Jury - conseils et recommendations pour réussir l'épreuve **Entretien avec Jury**
```Présentation de Dossier``` n'a aucune relation avec ```Dissertation```
### 3.2.1 Présentation du dossier - conseils et recommendations pour réussir l'épreuve **Présentation du dossier**

#### Storytelling
Présentez votre parcours de manière cohérente et logique menant à cette candidature.

Utilisez un diaporama :
- clair
- simple
- impactant

Ne lisez pas les slides.

#### Durée
Respectez la durée prévue :
20 minutes.

---

### 3.2.2 Discussion avec le jury - conseils et recommendations pour réussir l'épreuve **Discussion avec le jury**

#### Écoute active
Répondez précisément aux questions posées.  
Reformulez si nécessaire.

Appuyez vos réponses avec :
- exemples concrets
- expériences professionnelles

#### Attitude
Adoptez :
- contact visuel
- posture ouverte
- écoute respectueuse`
