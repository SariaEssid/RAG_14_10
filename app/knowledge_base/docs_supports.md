# Supports Pédagogiques – Preuves à fournir
Les documents pouvant être déposés incluent notamment :

- ```Fiche module``` (objectifs, contenus, méthodes d’enseignement, modalités d’évaluation)
- ```Supports de cours``` (diapositives, notes, polycopiés)
- ```Travaux dirigés (TD)``` et ```Travaux pratiques (TP)```
- ```Projets, devoirs ou quiz```
- ```Travaux réalisés par les étudiants```
- ```preuves de mes activités```
- ```Enregistrements audio ou vidéo de séances```
- ```Interactions pédagogiques``` (forums, échanges sur plateformes d’apprentissage)
