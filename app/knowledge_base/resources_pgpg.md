# Consulter, Télécharger et Accéder aux livrables : Dossier, Production rdi, Capsules pédagogiques, Production, Dissertations(FR/EN), Séquence d’enseignement, Plateforme de TP, Supports pédagogiques, production, connaissance de base, connaissance (Mots clés : extraire, accéder, télécharger, consulter, acceder)

Selon votre rôle, tu peux accéder (télécharger, consulter) aux livrables :
- Production rdi
- Capsules pédagogiques (FR/EN)
- Production
- Dissertations (FR/EN)
- Séquence d’enseignement
- Plateforme de TP
- Supports pédagogiques
- dossier
- connaissance de base
- connaissance

#### 👤  Si tu est un **ÉVALUATEUR** : tu as des candidats affectés à toi -> tu peut accéder aux documents personnels déposés par tes propres candidats via ces étapes :
1. L'évaluateur accéde à l'interface d'évaluation
2. L'évaluateur sélectionne la ```spécialité``` et le ```grade``` de son candidat.
3. L'évaluateur choisit le ```nom de son candidat``` dans la liste.

Une fois le profil chargé, cliquez sur la ligne d'un fichier pour le visualiser ou télécharger via l'icône de téléchargement.

---

#### 👤  Si tu est un **CANDIDAT** : tu a déposé des documents personnels -> tu peut accéder à tes propres dépôts et livrables via ces étapes :
1. Le candidat accéde à l'onglet de ```Mes Livrables``` via compte avec rôle ```Candidat``` (cet onglet n'xiste pas pour compte ```Évaluateur```).
2. Le candidat clique sur son propre document pour le consulter ou télécharger via l'icône de téléchargement.

---

📄 **Exemples de Specialité :**
- Technologies de l'information, Math, Électromécanique, Génie Civil, Génie Énergétique, Langues

⚠️ ```Plateforme de TP```(épreuve de Production) est différente de ```Plateforme PGPG``` (systeme de gestion de passage de grades)

#### Évaluateur ne trouve aucune spécialité ou aucun grade :

Il n'y a aucun candidat affecté à cet évaluateur :

-> Donc l'Évaluateur n'a aucun candidat à evaluer ce qui résulte :
- aucun grade n'est trouvé pour sélectionner
- aucune spécialité n'est trouvée pour sélectionner

## Je veux accéder à la liste des livrables du candidat XXX, comment faire ?

Seul l'évaluateur peut accéder à la liste des livrables du candidat affecté à lui pour les évaluer via ces étapes :
1. L'évaluateur accéde à l'interface d'évaluation
2. L'évaluateur sélectionne la ```spécialité``` et le ```grade``` de son candidat.
   Si l'évaluateur ne trouve aucune ```spécialité``` ou ```grade``` pour sélectionner → Il n'a aucun candidat affecté à lui → Il n'a rien à évaluer
3. L'évaluateur choisit le ```nom de son candidat``` dans la liste.

Une fois le profil chargé, l'évaluateur clique sur la ligne d'un fichier pour le visualiser ou télécharger via l'icône de téléchargement.

## Évaluateur ne trouve aucune spécialité ou aucun grade :

Il n'y a aucun candidat affecté à cet évaluateur :

-> Donc l'Évaluateur n'a aucun candidat à evaluer ce qui résulte :
- aucun grade n'est trouvé pour sélectionner
- aucune spécialité n'est trouvée pour sélectionner
